# Login empresarial // Simple Login 🕋🏗 ⚙️

Este login muestra un acceso a un panel de admin que agrega usuarios y les asigna un rol, admin y user. El admin tiene los permisos de agregar y eliminar usuarios y los usuarios tienen el permiso de agregar, eliminar o actualizar tareas. 

Este proyecto demo quiere demostrar los siguientes puntos: 
1. Manejo de NSQl databases
2. Hacer scripts en javascript para manejar datos
3. Hacer estilos en CSS
4. Manejo de IA para la construcción de software 


This is a basic login for a enterprise. You can do it two roles, first de admin for registration of users, and the user for managing tasks. This demo trys to show profidency in the next themes: 

1. Managing NoSql DBases
2. Scripting in js for connecting the Dbases
3. Styling in Css
4. Managed AI for software Development
